# 两座电梯派梯算法

## 项目简介

本项目实现了一个智能的两座电梯派梯调度算法,能够根据电梯的当前位置、运行方向、载客量等因素,智能地选择最合适的电梯响应乘客的呼叫请求,以最小化乘客等待时间并优化电梯运行效率。

## 核心功能

### 1. 电梯调度算法

算法考虑以下因素来选择最优电梯:

- **距离代价**: 电梯到达请求楼层需要移动的距离
- **方向匹配**: 电梯运行方向是否与请求方向一致
- **顺路检测**: 请求楼层是否在电梯当前运行路径上
- **容量限制**: 电梯是否满载
- **优先级排序**:
  - 顺路的电梯优先级最高(+10分)
  - 空闲电梯次之(+5分)
  - 载客少的电梯优先

### 2. 代价计算方法

#### 空闲电梯
- 代价 = 楼层距离

#### 同方向顺路
- 代价 = 楼层距离(最优情况)

#### 同方向不顺路
- 需要先完成当前方向的任务再返回
- 代价 = 到达最远目标楼层的距离 + 从最远目标返回请求楼层的距离

#### 相反方向
- 需要等待电梯完成当前方向的所有任务
- 代价 = 到达最远/最近目标楼层的距离 + 从该点到请求楼层的距离

#### 满载电梯
- 代价 = 无穷大(不会被选中)

## 文件说明

- `elevator_dispatch.py`: 电梯派梯算法的主要实现
  - `Direction`: 电梯运行方向枚举(UP/DOWN/IDLE)
  - `Elevator`: 电梯类,包含状态管理和代价计算
  - `ElevatorDispatchSystem`: 调度系统,实现派梯逻辑

- `test_elevator.py`: 完整的测试套件
  - 单元测试: 测试电梯基本功能
  - 系统测试: 测试调度系统
  - 场景测试: 测试复杂实际场景

## 使用方法

### 运行演示

```bash
python3 elevator_dispatch.py
```

这会运行一个演示程序,展示不同场景下的电梯调度决策。

### 运行测试

```bash
python3 test_elevator.py
```

测试套件包含14个测试用例,覆盖各种场景:
- 基本功能测试
- 负载均衡测试
- 容量限制测试
- 方向冲突处理测试
- 高峰期场景测试

### 在代码中使用

```python
from elevator_dispatch import ElevatorDispatchSystem, Direction

# 创建调度系统(2部电梯,20层楼)
system = ElevatorDispatchSystem(num_elevators=2, max_floor=20)

# 派遣电梯响应请求
elevator = system.dispatch(request_floor=10, direction=Direction.UP)

# 打印系统状态
system.print_status()
```

## 算法特点

1. **智能优先级**: 在代价相同时,优先选择顺路的电梯,提高响应效率
2. **负载均衡**: 考虑电梯的当前载客量,避免单部电梯过载
3. **方向感知**: 充分利用电梯运行方向,减少不必要的等待
4. **容量保护**: 满载电梯不会被派遣,确保服务质量
5. **可扩展性**: 设计支持扩展到多部电梯的场景
